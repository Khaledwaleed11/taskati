# Taskatii 📝

Taskatii is a simple and user-friendly Flutter task management application
that helps users organize and manage their daily tasks.

## 📱 About The Project

Taskatii allows users to:

- Create new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- View completed tasks
- Move tasks between active and completed tasks
- Create a user profile
- Add a profile picture using the camera or gallery
- Register and login
- Logout from the application

## ✨ Features

- 🔐 Login & Register
- 📝 Add Tasks
- ✏️ Edit Tasks
- 🗑️ Delete Tasks
- ✅ Complete Tasks
- 📋 View Done Tasks
- 👤 Profile Screen
- 📷 Camera & Gallery Image Picker
- 🔒 Permission Handling
- 💾 Local Data Storage using Hive
- 🎨 Clean and simple UI

## 🛠️ Technologies Used

- Flutter
- Dart
- Hive
- Hive Flutter
- Image Picker
- Permission Handler
